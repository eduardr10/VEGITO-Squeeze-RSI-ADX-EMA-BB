# 🌌 VEGITO: Squeeze + RSI + ADX + EMA + BB

**VEGITO** es un motor de análisis técnico integral para TradingView (Pine Script v6) diseñado para traders que buscan la máxima confluencia con la mínima fatiga visual. Este script fusiona cinco capas críticas de datos en un solo ecosistema visual, eliminando el ruido y resaltando oportunidades de alta probabilidad.

---

## 🛠️ Componentes Técnicos (Valores por Defecto)

El script viene optimizado de fábrica con los estándares profesionales más robustos:

* **EMA 50:** Actúa como el eje de valor y filtro de tendencia principal.
* **Bandas de Bollinger (20, 2):** Establecen los límites de volatilidad y las zonas de sobreextensión del precio.
* **Squeeze Momentum:** Histograma dinámico que detecta fases de **Compresión (Rojo)** y **Liberación de Energía (Verde)**.
* **RSI Adaptativo (14):** Mide la velocidad del movimiento para identificar techos y suelos técnicos.
* **ADX (14) con Umbral Dinámico:** Filtra los mercados laterales, indicando con un check (✅) cuándo existe fuerza tendencial real.

---

## 👁️ Tooltip "Vegito (Análisis de 50 Velas)

La característica más innovadora de **VEGITO** es su etiqueta de resumen inteligente. Al pasar el cursor sobre el icono **👁️** en el gráfico de precios, el script despliega un diagnóstico basado exclusivamente en el historial de las **últimas 50 velas**:

1.  **Dominancia Alcista:** Porcentaje de control de los compradores sobre el promedio móvil en el periodo de lookback.
2.  **Rango Histórico Real:** Identifica el máximo y mínimo exactos de las últimas 50 barras.
3.  **Posición en Canal (%):** Indica matemáticamente en qué punto del rango se encuentra el precio actualmente, ideal para evitar comprar techos o vender suelos.

## 🚀 Instrucciones de Instalación

Como este script no está publicado en la biblioteca pública de TradingView, sigue estos pasos para usarlo:

1.  Copia el código completo del archivo `Vegito.pine` de este repositorio.
2.  En **TradingView**, abre la pestaña inferior llamada **Pine Editor**.
3.  Borra cualquier código existente y pega el código de VEGITO.
4.  Haz clic en **Añadir al gráfico** (Add to Chart).
5.  ¡Listo! Puedes guardarlo en tus indicadores personales haciendo clic en el botón **Guardar**.
